# swcode 0.14.0

Released 2026-11-16.

Pairing lives in one place: Settings → Computers. *Connected devices* lists the phones and computers paired with this swcode, takes the number a device shows, and shows the address a phone opens as a QR code; *Connect a device* keeps this app's computers and adds one, which opens its name and colour once it is paired. The Phone topic is gone.

The Android app can use the camera for QR codes, looks for its own next release when it comes back to the front (and on *Look now*), and the phone's frame clears the status bar. Windows is `swcode-desktop.exe` again — it installs itself — and Linux gains a `.deb` with each release.
