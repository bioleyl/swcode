# swcode 0.7.0

Released 2026-11-09.

swcode 0.7 gives a project a list of what it still has to do, and lets a new session start on the todos you pin to it.

## Highlights

- **Project todos**: a project's page has a Todos tab, where you add what needs doing, tick it done, edit its words or delete it. A todo that a session started on links back to that session. A new session's page shows the project's open todos: tick the ones it should work on, and they go to the agent after your first message, and stay listed in the session.
- **`/todo` in the composer**: adds a todo to the folder the session works in, from the conversation, without interrupting the agent.

The [changelog](https://github.com/bioleyl/swcode/blob/main/CHANGELOG.md) has the full list.

## Upgrading

Nothing in your settings changes: a project starts with no todos. Your projects and sessions are kept as they are. swcode 0.6 offers this release itself. Otherwise, install or update with the command in the [README](https://github.com/bioleyl/swcode#install), or download the release for your platform. Checksums are published with the release.
