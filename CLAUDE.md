# swcode: notes for working on the code

Load the skills before writing code: `jadis` (the frontend library), `jlib:jlib` and `syware-ux:syware-ux` (the
components the app is built from, and how SyWare apps behave), and `coding-style` (named constants, guard clauses,
exhaustive mappers, types in `types/` directories).

The project's notes are in `AGENTS.md`, which swcode's own agent reads too: add to them there, not here.
